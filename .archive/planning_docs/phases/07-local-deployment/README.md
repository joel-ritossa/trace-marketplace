# Phase 07: Local Deployment

## Purpose

Make the project easy to run, inspect, and evaluate locally.

## Focus Questions

- What is the minimum setup command?
- Which services must run locally?
- What environment variables are required?
- How are synthetic fixtures seeded?
- How does a user verify upload, search, inspection, listing, and download behavior?
- What third-party or cloud services, if any, are required?

## Outputs

- Local setup instructions.
- Seed data instructions.
- Smoke test command.
- Demo walkthrough.
- Documented third-party or cloud dependencies.
- Known limitations.

## Existing Docs

- [Initial spec](../../init-spec.md)
- [Expectations synthesis](../../expectations-synthesis.md)

## Decision Gate

The project is ready for local evaluation when a fresh local run can exercise the demo path without manual operator work.
