# Phase 01: Product Thesis

## Purpose

Define what Trace Marketplace must prove in the trial window and what is intentionally deferred.

## Focus Questions

- What is the smallest valuable version of Trace Marketplace?
- What must contributors and consumers be able to do without operator help?
- Which marketplace concepts need to be visible now, and which can wait?
- What does a successful demo prove about trace ingestion, search, and inspection?

## Outputs

- Product thesis.
- Demo success criteria.
- In-scope and out-of-scope boundaries.
- Priority order for product and engineering work.
