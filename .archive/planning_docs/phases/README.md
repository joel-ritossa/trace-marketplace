## How To Use These Docs

- Keep each phase focused on the decisions needed for the next phase.
- Link to existing docs instead of duplicating durable context.
- Move settled decisions into [../decisions](../decisions/README.md).
- Move unresolved product, architecture, or data questions into [../questions](../questions/).
- Keep implementation details out of phase docs until they are needed to make a decision.
