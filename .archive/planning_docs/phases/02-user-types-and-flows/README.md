# Phase 02: User Types And Flows

## Purpose

Define the people using the product and the workflows the first version must support.

## Focus Questions

- Who uploads trace data?
- Who searches, inspects, evaluates, and downloads trace data?
- What must happen when upload, validation, parsing, or search fails?
- Where do contributor and consumer flows meet?

## Outputs

- User types.
- Contributor flow.
- Consumer flow.
- Shared handoff states such as private, shared, and listed.
- Flow-specific UI and API state requirements.

- [User types and flows](../../user-types-flows.md)

## Decision Gate

Before moving on, the first version should have only the user types needed to drive upload, inspection, search, download, and lightweight listing behavior.
